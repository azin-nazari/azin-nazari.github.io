# azin-nazari.github.io

Source of [azin-nazari.github.io](https://azin-nazari.github.io), built with [Quarto](https://quarto.org) and published by GitHub Actions on every push to `main`.

Posts are in `posts/`. The data and code behind a post, when it has any, are in `research/`, with a README explaining how to reproduce its tables and figures.
